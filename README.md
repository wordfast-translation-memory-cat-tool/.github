Wordfast is a family of computer-assisted translation tools designed to be lighter and more approachable than the heaviest CAT suites. It centers on translation memory so translators can recycle prior work, keep terminology consistent and finish jobs faster without a steep setup.

Wordfast Classic works as a macro layer inside Microsoft Word, which appeals to translators who love Word's environment, while Wordfast Pro is a standalone, cross-platform editor with batch processing and TM management. Both aim for speed, low cost and compatibility with industry-standard TMX and TBX files.
